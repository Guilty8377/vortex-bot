# Vortex

Vortex is a paper trading terminal for new Solana memecoins. The tokens and prices are real and live, but the money is pretend.

- New tokens and migrations: PumpPortal free websocket
- Prices, volume and buys/sells: DexScreener free API
- Everything you do is saved in your own browser

Live site: https://guilty8377.github.io/vortex-bot/

Made for a BTEC Unit 14 Business Online assignment. Not financial advice.
